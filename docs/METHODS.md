# Methods template — adapt before publication

Cell Ranger V(D)J was used to process 10x Genomics 5′ immunoglobulin libraries from two independently barcoded sheep samples, using a validated custom sheep V(D)J reference (reference construction and accession described separately). For each sample, the original sequencing library (PUR1 or PUR2) and two separately sequenced re-amplification libraries (IgG- and IgM-enriched) derived from the same barcoded cell preparation. Productive, cell-associated IGH, IGK and IGL contigs were extracted from Cell Ranger `filtered_contig_annotations.csv`. Within each biological sample, contigs were consolidated by cell barcode. Exact matching reconstructed variable-region nucleotide sequences with matching chain and constant-gene annotations were collapsed across libraries, retaining all contributing run identifiers. Variable-region sequences were assembled in order from FR1, CDR1, FR2, CDR2, FR3, CDR3 and FR4; nucleotide translations were compared with the concatenated annotated amino-acid regions. Each cell was assigned an exclusive chain-composition category, including IgG, IgM, IgA, IgD, IgE, unknown heavy isotype, single light chain, strict 1H1L, and multichain. Integration was performed separately for sequencing 2 and for the complete sequencing 1+2 dataset. Library-level category observations and post-integration unique barcode counts were reported separately. Only cells with exactly one distinct productive heavy and one distinct productive light chain were retained in the strict 1H1L dataset; possible pair combinations from multichain cells were reported separately.
